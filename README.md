## 🧭 关于我

- 🏠 家里跑着一台 **fnOS NAS**，71 个容器、几十个服务，能自建的绝不用第三方
- 🎬 沉迷 **媒体自动化**：订阅 → 搜资源 → 挑画质 → 入库 → 刮削 → 播放，全程不想手点
- 🤖 喜欢把**真实流程**做成工具：多智能体编排、订阅管理、抢购、签到这些重复动作
- 🐳 交付习惯：**一条 `docker run` 能起来的**,才算做完
